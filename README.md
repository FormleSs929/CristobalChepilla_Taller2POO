# Taller 02 – POO

Cristóbal Nicolás Chepilla Arriagada, 21873055-8, FormleSs929

## Descripción

Programa en Java que simula un juego de Pokémon por consola, permitiendo capturar Pokémon, combatir contra gimnasios y administrar equipos.

## Funcionalidades

- Nueva partida
- Continuar partida
- Captura de Pokémon
- Sistema de combate
- Tabla de efectividad de tipos
- Revisar equipo
- Acceso al PC
- Curar Pokémon
- Guardar partida
- Persistencia de datos mediante archivos

## Archivos utilizados

- Pokedex.txt
- Registros.txt
- Gimnasios.txt
- AltoMando.txt
- Habitats.txt
